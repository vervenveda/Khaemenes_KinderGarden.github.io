- 5 lessons per unit
- 180 daily lessons
- 36 printable unit packets
- 36 weekly mastery assessments
- Midyear demonstration / midterm
- Final readiness demonstration / final exam
- Teacher tools
- Local student record tracker
- 80% completion certification logic
- Standards-style internal crosswalk
- No outside fonts, scripts, images, libraries, or curriculum dependencies ## Certification Rule Certificate unlocks when: 1. Weekly assessment average is 80% or higher.
2. Midterm score is 80% or higher.
3. Final score is 80% or higher.
