# Kindergarten Reading Video Certification

Status date: 2026-10-28

## Release rule

Every core Kindergarten reading placement requires a lawful full-story video pathway.

### Copyrighted / contemporary books
- Required status: `authorized-external-video`.
- Khaemenes links to the rightsholder-authorized Storyline Online book page.
- Do not download, screen-capture, mirror, or rehost Storyline Online video.
- Do not embed Storyline media unless explicit permission is obtained.
- Storyline's own Classroom Player is the preferred alternate when YouTube is blocked.
- If the official authorized video becomes unavailable, mark the placement `needs-replacement`; never substitute an unofficial upload.

### Public-domain books
- Required status before worldwide release: `academy-public-domain-video-certified`.
- The specific edition/image source must be verified public domain / reusable.
- Academy may create an original narration/presentation from reusable source material.
- Narration, captions, timing, audio, and assembled video must be Academy-original or separately licensed.
- A scan/PDF alone does not satisfy the video gate.
- Until an actual playable Academy presentation exists, status remains `academy-public-domain-video-required`.

## Public-domain Academy production queue

The data file is authoritative for placements tagged `academy-public-domain-video-required`. Production should deduplicate repeated source works before narration so one certified Academy video can serve every placement using the same title/edition.

For each production:
1. Verify exact source item and rights statement.
2. Save source metadata and attribution.
3. Prepare age-appropriate narration script faithful to the public-domain text.
4. Produce original narration with optional captions.
5. Create accessible visual pacing from reusable page images.
6. Add transcript/captions and audio controls.
7. Test desktop, tablet, phone and offline/local fallback where supported.
8. Record final local asset path and checksum.
9. Change the reading record to `academy-public-domain-video-certified` only after playback QA passes.

## Accessibility

A physical copy is optional enrichment. Lack of a physical book must never block a child from the weekly reading experience. Video/listen access is the worldwide baseline; text/full-book access is additive where lawful.
