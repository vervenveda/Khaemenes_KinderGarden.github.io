# Khaemenes Academy · Kindergarten Social Studies
## My World, My Community

Canonical route: `social-studies/index.html`

This is the Kindergarten Social Studies course for Khaemenes Academy Kinder Garden.

### Course record
- 36 weeks
- 180 Monday–Friday lesson blocks
- 9 four-week units
- 80% weekly mastery threshold
- randomized five-question weekly checks drawn from six-item age-appropriate banks
- best score retained; fresh form on retake
- teacher/read-aloud support allowed so reading fluency is not mistaken for Social Studies mastery
- local browser records, JSON export/import, printing, portfolio evidence
- no external libraries

### Disciplinary strands
Inquiry; Civics & Government; Geography; History; Economics; Culture & Society; Informed Action.

### Instructional rhythm
Monday builds background and questions. Tuesday applies a disciplinary tool. Wednesday is a source/evidence lab. Thursday asks learners to create, decide, compare, or take a safe informed action. Friday is mastery, correction, reflection, and portfolio evidence.

### Progression
Week 1 is open. Each next official week unlocks when the prior week's best mastery check is 80% or higher. A sub-80 attempt triggers review, correction, and a fresh retake.

### Existing History Adventure
The existing `apps/History_curriculum_index.html` remains preserved as an optional practice/adventure application. It does not replace the canonical 36-week Social Studies course.

### Teacher convenience code
`KHAEKSS`

This code is **not secure authentication**. GitHub Pages is static. Do not store sensitive student information here.

### Design basis
The course is informed by the NCSS C3 Inquiry Arc and recurring Kindergarten strands in current state frameworks, including community, civic life, geography, historical time and sources, economics, culture, and age-appropriate informed action. It is designed for national portability; it does not claim accreditation or automatic legal acceptance in every jurisdiction.

## State/local localization

Kindergarten follows the Academy-wide **national-core / state-local-overlay** rule. State and local maps, public services, symbols, historical sources, Indigenous histories, environments, and community examples should be integrated where appropriate without removing national competencies or changing the 80% mastery threshold.

See `STATE_LOCALIZATION_GUIDE.md`.
