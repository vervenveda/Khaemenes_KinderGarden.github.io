Essential question

How can tools help us create safely?

Project

Build an unplugged robot map, test instructions, repair one unclear step, and explain one safety or privacy boundary.

Materials

Paper, crayons, blocks or counters, three-step picture cards, a hand-drawn 3×3 grid, and arrow cards. No internet access or working device is required.

My week in one idea

Tools help us do a job. Instructions work best when another person can follow them. Some tools need adult permission. Private information—such as a home address, password, or personal location—must not be shared in a learning activity.

Draw a tool and show what it helps you do.

Explain or dictate: A tool that helps me is __________ because __________.

Monday · Match a Tool to a Task

Learning target: Match three familiar tools to appropriate tasks and explain one safe-use rule, including when adult permission is needed.

Try it

  1. Draw a pencil, magnifier, crayon, or blocks.
  2. Draw or tell what job the tool can help with.
  3. Circle a tool or situation where you should ask a grown-up first.
Draw, match, label, or attach evidence here.

Explain your thinking: This tool helps with __________. I ask first when __________.

Check my idea: Does my choice fit the task? Can I name one safety rule?

Adult observation / feedback: What did the learner match? What safety rule did they explain? __________________________________

Tuesday · First, Next, Last

Learning target: Create and follow a three-step unplugged algorithm, then check whether another person can follow it.

Try it

Choose a familiar routine, such as making a drawing or putting blocks away. Draw one step in each box and number them 1, 2, 3.

FIRST · What happens first?
NEXT · What happens next?
LAST · What happens last?

Test it: Ask a partner or grown-up to follow your sequence. If an order is confusing, change one card and test again.

Explain: I changed __________ because __________.

Adult observation / feedback: Did the learner sequence the steps and notice a result when the order changed? __________________________________

Wednesday · Guide the Paper Robot

Learning target: Guide a paper token through a simple grid, use directional words, and repair one unclear or incorrect instruction.

Try it

Draw a 3×3 grid. Mark START and FINISH. Use arrows to show one-square moves from one square to a neighboring square.

Draw a 3 × 3 grid here. Add the start, finish, and arrows.

Test and repair: Try your instructions with a token. If it reaches the wrong square, circle the step to change and draw a corrected arrow.

Explain: The step I fixed was __________ because __________.

Adult observation / feedback: Did the learner use one-square moves and correct an instruction after testing? __________________________________

Thursday · Make Instructions Clear

Learning target: Design a short set of tool-use or classroom instructions, test them with another person, and revise one unclear step for clarity or safety.

Try it

Choose an ordinary classroom job. Create three to five steps another person could follow without you filling in missing information.

Draw or write your instruction steps.

Partner test: Ask a grown-up or partner to follow the steps as written. Where did they need a question answered?

Revision: The unclear step was __________. I changed it to __________.

Adult observation / feedback: What did the tester do? Did the learner revise one step based on the test? __________________________________

Friday · Stop, Check, Ask

Learning target: Solve a new tool-and-sequence scenario, identify a digital privacy boundary, and explain a safe next step when unsure.

New example

A pretend drawing game asks for a home address before you can color. You do not need to enter an actual address for this activity.

What should you do? Draw or circle the safest first step, then explain why.

Draw a safe next step: stop, close the request, or ask a trusted grown-up.

Which information stays private? Choose from: a favorite color · a home address · a password · a personal location.

My explanation: I would __________ because __________.

Reflection: One instruction I improved this week was __________.

Adult observation / feedback: Record the learner's actual explanation or demonstration, not an answer supplied by the adult. __________________________________
