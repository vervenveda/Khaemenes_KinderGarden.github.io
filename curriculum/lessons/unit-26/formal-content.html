Teach · Practise · Correct · Transfer

Prerequisite retrieval: Retrieve Week 25's distinction between a symbol, its intended meaning, and the evidence a viewer uses to interpret it.

Explicit teacher model: Model how a fictional community symbol communicates an idea through visible features and context. Explain symbols can have different meanings across groups and that interpretation may be uncertain without a key or source.

Guided-to-independent practice: Compare three supplied symbols, name a visible feature for each, and match to a provided meaning card. Then ask the learner to explain one match with evidence.

Common misconception and correction: If the learner assumes a symbol means the same everywhere, show two fictional keys with different meanings. If meaning is guessed from color alone, inspect the whole design/context and mark uncertainty.

Fresh transfer check: Present an unfamiliar fictional symbol without its key. Ask what can be observed, what meaning might fit, and what additional information is needed before claiming certainty.

Evidence rule: Assess each criterion separately. The fresh transfer task uses a new example before hints; a correct guess without supporting evidence is not full reasoning mastery.

Teach · Practise · Correct · Transfer

Prerequisite retrieval: Retrieve the Week 10 map legend and Week 7 attribute-sorting routine; state the classification rule before sorting.

Explicit teacher model: Model sorting symbols by one visible attribute and then by a different attribute. Explain that one symbol can belong to different groups depending on the question/rule.

Guided-to-independent practice: Sort six symbol cards by feature, verify every card, and resort the same cards under a new rule. Learner explains why group membership changed even though the symbols did not.

Common misconception and correction: If a symbol is assigned to only one possible category, demonstrate different valid rules. If the learner confuses a sort category with the symbol's social meaning, separate visible feature from interpretation.

Fresh transfer check: Give a new mixed symbol set and ask for two distinct valid sorts, each with a stated rule, plus one visible clue that does not by itself establish a symbol's full meaning.

Evidence rule: Assess each criterion separately. The fresh transfer task uses a new example before hints; a correct guess without supporting evidence is not full reasoning mastery.

Teach · Practise · Correct · Transfer

Prerequisite retrieval: Retrieve observation-vs-inference and source checking from Weeks 4, 20, and 21.

Explicit teacher model: Model interpreting a fictional emblem by listing observed features, a context clue, a possible interpretation, and an uncertainty. Never teach a guessed meaning as a universal fact.

Guided-to-independent practice: Use a provided fictional source note to interpret two symbols, then offer a third without a note. Learner marks what is supported, inferred, or unknown and explains why.

Common misconception and correction: If a decorative feature is treated as proof of history or group identity, ask what the source actually states. If a claim generalizes to a whole culture/group, limit it to the supplied example.

Fresh transfer check: Present an unfamiliar fictional civic/classroom symbol with a short source note. Ask for one supported interpretation, one observation, and one question that remains open.

Evidence rule: Assess each criterion separately. The fresh transfer task uses a new example before hints; a correct guess without supporting evidence is not full reasoning mastery.

Teach · Practise · Correct · Transfer

Prerequisite retrieval: Retrieve original-design goals from Week 7 and the distinction between evidence-based meaning and guesswork.

Explicit teacher model: Model designing an original belonging/agreement symbol with two purposeful features; explain how a legend or label makes the intent readable to someone else.

Guided-to-independent practice: Learner sketches/builds a new symbol, writes/dictates a key, and asks another person to interpret it. Revise one feature if the interpretation does not match the intended meaning.

Common misconception and correction: If the design accidentally resembles a restricted or culturally specific symbol, choose a more original design; do not copy sacred/closed symbols. If the meaning is only known to the creator, add a clear key or label.

Fresh transfer check: Give a new design constraint, such as communicating shared care without using words. Ask the learner to create an original symbol, explain two purposeful features, and test whether a new reader can interpret it using the key.

Evidence rule: Assess each criterion separately. The fresh transfer task uses a new example before hints; a correct guess without supporting evidence is not full reasoning mastery.

Teach · Practise · Correct · Transfer

Prerequisite retrieval: Retrieve visible feature, stated sorting rule, source-supported interpretation, and original design criteria before reviewing examples.

Explicit teacher model: Model a short evidence explanation: describe the symbol, cite the key/source, state what it may mean, and mark what cannot be concluded.

Guided-to-independent practice: Use guided retrieval and repair an unsupported interpretation, then provide a new fictional symbol set and a fresh design prompt. Score observation, rule-based classification, source reasoning, and design communication separately.

Common misconception and correction: If the child makes a correct guess without evidence, do not score source reasoning as mastered. If they sort correctly but cannot explain the rule, assess the classification and explanation separately.

Fresh transfer check: Use unseen fictional symbols and a novel design constraint. Ask for two-rule sorting, one source-supported interpretation, one uncertainty, and an original symbol with a readable key.

Evidence rule: Assess each criterion separately. The fresh transfer task uses a new example before hints; a correct guess without supporting evidence is not full reasoning mastery.
