## Rules before changing public main
- Inspect the exact latest main file and current blob SHA.
- Preserve all 36 weeks, 180 lessons, 36 unit mastery routes, weekly hub, midterm, final, games and certificates.
- Keep lesson data and active mentor compatibility intact unless a verified replacement exists.
- Record observed browser behavior separately from source and static checks.
- Do not rewrite private STOS architecture or upload child records to this public repository.
- Do not permit a GitHub workflow to overwrite pages automatically.
- Do not delete divergent copies merely because their filenames match.
- Require verified backup/rollback provenance before destructive edits.
- Do not promote a provisional browser score to official certification without trusted server receipt.
- Verify game correctness with known-answer fixtures, and ensure replay cannot reset unrelated saved progress.

## Runtime acceptance matrix to execute when environment is available
- Routes: open lesson, assessment, self-check, and links from the homepage on deployed origin.
- Accessibility: keyboard-only operation, WCAG focus, motion reduction, non-color feedback, 320px viewport.
- Audio: start by user gesture, playback available/unavailable states, mute, rapid interaction.
- Learning: no repeated-question trap, no hidden units, correct grading, retries preserved, inclusive options.
- State: reload, offline-to-online, multi-learner isolation, duplicate events, cross-tab interactions and loss prevention.
- Privacy: public HTML and static files contain no learner profile, token, keys, logs, or internal STOS topology.
- Release: compare before/after repository file inventory and document any intentional removals.
